# Explicar componente
Activación: `/explain`

Si el usuario pasó un archivo o símbolo después del comando, úsalo. Si no, usa el archivo activo.

## Pasos
1. **Contexto:** Analiza el archivo y sus dependencias directas.
2. **Resumen:** En 1-2 frases, qué hace el componente.
3. **Flujo de datos:** Entradas, transformaciones principales y salidas.
4. **Integración:** Cómo encaja en la arquitectura.
5. **Salida:** Informe en Markdown para el usuario, en español.
